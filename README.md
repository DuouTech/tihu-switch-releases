# Tihu-Switch 官方发行

本仓库仅提供 Tihu-Switch 安装包、更新清单、校验和与必要许可。应用源码和构建配置由 DuouTech 的私有仓库维护。

正式版本发布后，可在 [Releases](https://github.com/DuouTech/tihu-switch-releases/releases) 下载 Windows x64 安装包。请使用 Tihu-Switch 自己的更新渠道；Duou-Switch 的安装身份、资料目录及更新签名相互独立。

安装包的 `.sig` 是 Tauri/minisign 更新签名，不等同于 Windows Authenticode 证书签名。校验文件与每次发布一同提供。

Tihu-Switch 基于与 Duou-Switch 共用的核心，继承 CC Switch 的 MIT 许可及第三方署名。
